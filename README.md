# 素数ゼミはなぜ13年と17年なのか — 論文のモデルで確かめる

北米の周期ゼミ（13年ゼミ・17年ゼミ）の周期が素数なのはなぜか。その説明として出された2つの説のモデルを、
自前で書き直して確かめた記録です。
YouTube チャンネル「AIのなかみ」の動画で使ったコードと、検証の基準・結果をそのまま置いています。

- **天敵説**: Markus, M., Schulz, O., & Goles, E. (2002). Prey population cycles are stable in an evolutionary model if and only if their periods are prime. *ScienceAsia*, 28, 199–203.
- **交雑説**: Tanaka, Y., Yoshimura, J., Simon, C., Cooley, J. R., & Tainaka, K. (2009). Allee effect in the selection for prime-numbered cycles in periodical cicadas. *PNAS*, 106(22), 8975–8979.
- **交雑説（整数版）**: Yoshimura, J., et al. (2009). *Evolution*, 63, 288–294.（使った投稿前原稿の題は "The evolution of prime number intervals in periodical cicadas"）

論文の式と数値だけを使い、コードはすべて書き直しています（論文にコードはありません）。
Tanaka (2009) と Yoshimura (2009) は、静岡大学学術リポジトリにある投稿前の原稿の式と数値を使いました。
Tanaka (2009) の式は掲載版と同じであることを確かめていますが、Yoshimura (2009) の掲載版は読めていません。
論文・原稿の本文はこのリポジトリに含めていません。

## 5つの検証

| | 問い | コード | 結果 |
|---|---|---|---|
| 検証1 | 天敵説のモデルで素数が選ばれるか・「地上に出た回数で割る」仮定を外すとどうなるか | `sim_predator.py`・`boot_1b.py` | `1a.json`・`1b_*.json`・`tie*_1b_*.json`・`boot_*.json` |
| 検証2 | 交雑説（Tanaka 2009）の Fig 1・Fig 5 が出るか | `sim_hybrid.py`・`sim_hybrid_plane.py`・`sim_hybrid_eq4.py` | `hybrid*.json` |
| 検証3 | 整数版の交雑説（Yoshimura 2009）の Fig 1 が出るか・産卵数を一定にするとどうなるか | `sim_yoshimura.py`・`sweep_yoshimura.py`・`constC_yoshimura.py` | `yoshimura*.json` |
| 検証4 | 突然変異の幅・受け入れ方・集団（遺伝的アルゴリズム）で素数が残るか | `sim_ga.py` | `4a.json`・`4b.json`・`4b_prey_only.json` |
| 検証5 | 短い周期から始めると、近くの素数で止まるか | `sim_stuck.py` | `5_stuck.json` |

判定の基準は、結果を見る前に `CRITERIA.md` に書きました。結果を見たあとに基準は動かしていません。
結果を見たあとに足した確認（検証2の平面・検証3の掃引と産卵数一定・検証4の捕食者固定）は、そうだと分かるように書いています。
外れた見立ても、そのまま残しています。

### 結果の要点
- **検証1（天敵説）**: 10×10 のセルオートマトンで、初期配置1万通りのうち、最後に残る周期は 98.6% が素数（最初は 31%）。
  多かったのは 17年（13.6%）と 13年（12.9%）。ただしこの2つの差の 95% 区間は 0 をまたぐので、どちらが上かは言えない。
- **ただし 13・17 は「地上に出た回数で割る」仮定から来る。** 論文は「出るたびにコストがかかる」として、点数を出た回数で割っている。
  これを外して1年あたりで比べると、素数は 94.8% 残るが、いちばん多いのは 5年（26.5%）で、7・2・3年が続く。
- **検証2（交雑説）**: 論文の式と数値どおりに組むと、短い周期ほど速く増えて、素数だけが残ることはなかった（条件 1,395 通り）。
  論文に書かれていない実装の約束で結果が変わる余地があるので、論文が誤りだとは考えていません。
- **検証3（整数版）**: Fig 1A（200年目に 13・17・19年だけが残る）は再現した。Fig 1B（700年目）と Fig 1C（600年目）は、原稿の数値そのままでは合わなかった。
  産卵数を周期に比例させる仮定をやめて一定にすると、最後まで残るのは 10年か 10・11年になった。
- **検証4**: 1組の山登りで素数が残るのは「同点なら動かない」ときだけ。集団にすると約9割が素数に戻る。
  天敵の周期を1種類に固定すると素数は 3〜4割しか残らず、2〜10年に散らばらせると約9割になる（この確認は結果を見たあとに足したもの）。
- **検証5**: 天敵2〜20年・1回の変化±3年だと、2〜5年から始めたセミは 100本中100本が 11年で止まった。いちばん得な 23年以上には届かない。
  天敵2〜10年では、判定の基準に届かなかった（11・13年は 50本で、残りは 17・19年に分かれた）。13・17年が特に選ばれることはなかった。

2つの説に共通するのは、素数の長い周期が勝つのは、短い周期の有利を打ち消す仮定を入れたときだけ、という点です
（天敵説では出るたびのコスト、交雑説では長い周期ほど卵が多いこと）。
ただし、その仮定があれば 13・17 年になるわけではありません（下の訂正）。

### 訂正（2026-11-17）
`CRITERIA.md` の検証5に「適応度は世代数で割らない」と書いたのは誤りでした。
検証4・5の式 1 − 2·mean gcd(X,Y)/X は「地上に出た1回あたり」の損得で、検証1の「割る」版と同じ形です。
つまり、検証4・5のセミも「出るたびのコスト」の仮定のもとで進化していて、それでも 13・17年にはなっていません。
13・17年が多くなったのは、検証1の空間のあるモデル（10×10・周り9マス）で、この仮定と組み合わさったときでした。

## `published/` について

動画を作ったときに出した結果です。`run_all.sh` で回し直すと、所要時間の欄（`sec`）を除いて同じ値が出ます（確認済み）。

## 注意

- これは数理モデルです。実際の周期ゼミの天敵や交雑のデータで確かめたものではありません。
  Markus ら自身も「周期ゼミに関係する周期的な天敵は、まだ見つかっていない」と書いています。
- 論文と食い違った点（Markus 2002 の 5×5 格子の結果など）は `CRITERIA.md` の各節と結果ファイルに残しています。
